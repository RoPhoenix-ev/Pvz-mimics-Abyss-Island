前往本仓库的 Releases 页面，展开对应版本的 Assets，下载发布的压缩包。

请下载发布附件，不要下载 GitHub 自动生成的 Source code 压缩包。

启动方法

将压缩包完整解压到一个独立文件夹，不要在压缩包内直接运行。

打开文件夹中的挑战启动器。

按启动器提示选择或导入原版《植物大战僵尸》客户端。

通过启动器启动游戏。

在游戏的生存模式中选择 泳池无尽，进入挑战。

游玩期间请保持启动器运行。下次继续游戏时，也请通过启动器启动。

保存与续玩

退出对局时，使用游戏内的保存退出功能。续玩时使用同一份启动器和游戏目录，读取保存的对局。

注意事项

本项目需要自行准备兼容的原版游戏客户端。

首次使用前，建议备份原版存档。

更新时请先退出游戏和启动器，并保留原有的存档文件。

分享给其他玩家时，请使用 Releases 中的发布包，避免将个人存档一并打包。

问题反馈

如遇到无法启动、闪退或续玩异常，请在 Issues 中说明：

使用的启动器版本和原版客户端版本；

问题发生前的操作；

报错截图或相关日志。
